## ⚡ About Me

I am a **Full-Stack & Systems Developer** based in India, passionate about building high-performance developer tools, media automation engines, and scalable backend infrastructure.

- 🚀 **Founder & Builder:** Architecting the **[Dusyn Ecosystem](https://dusyn.in)**, a suite of interconnected developer tools, media utilities, and automation engines.
- 🎬 **Flagship Launch:** **[Reelcraft](https://github.com/dusmamud/reelcraft)**, an open-source CLI automating beat-synced 9:16 vertical reels directly from codebases.
- 🛠️ **Core Stack:** TypeScript, Node.js, Go, Python, PostgreSQL, and Docker.
- 🧠 **Focus:** Autonomous AI Agent systems, local LLMs, and deterministic 60fps video rendering.
- 🤝 **Collaboration:** Open to freelance projects, engineering roles, and impactful open-source initiatives.

---

## 🎯 2026 Engineering Roadmap & Focus

- 🌐 **Scaling Dusyn:** Unifying core developer tools into a single high-availability API platform at [dusyn.in](https://dusyn.in).
- 🎬 **Autonomous Media CI/CD:** Building automated GitHub Actions for Reelcraft to render launch reels on every release.
- 🤖 **Agent Workflows:** Exploring autonomous code refactoring and AST transformation using local models.
- ⚡ **Low-Latency Backends:** Architecting distributed services in Go with zero-downtime database replication.
